# UI / UX

## Workspace Experience

The 3D world is the primary interface.

## Layout

- full viewport Canvas
- no page scroll while inside workspace
- persistent HUD
- drawers
- overlays
- modals

## Navigation

Task Board → HUD drawer
Dashboard → HUD drawer
Notifications → HUD panel
Meeting → overlay

## Simple Mode

2D fallback for:
- accessibility
- low-end devices
- WebGL unsupported

## Camera

Third-person perspective camera following the avatar.
