PHASE 16 — DASHBOARD
====================
 
PROMPT:
 
Create the workspace dashboard as a HUD overlay panel on top of the 3D world (per the UI/UX PARADIGM section), reachable from a persistent icon/button in the HUD — not a separate page that hides the 3D scene.
 
Display:
 
* current user
* work session
* check-in time
* current status
* current room
* assigned tasks
* recent submissions
* upcoming/active meetings
* notifications
Supervisor view should additionally show team presence (scoped to users they supervise, per the reporting structure) and relevant escalation notifications.
 
Include a personal "my activity history" view so users can see their own stored data, per the Compliance section.
 
Avoid turning the dashboard into a surveillance interface.
