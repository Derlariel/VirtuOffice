On mobile:

* reduce texture resolution
* remove expensive shadows
* reduce particles
* simplify lighting
* reduce animation complexity
* use touch controls
* make task board usable with touch
* ensure meeting controls remain easy to access
Verify WCAG 2.1 AA conformance at each breakpoint (contrast, tap target size, focus order).
 
Verify Thai and English text both render correctly (line length, wrapping, font support) at each breakpoint.
